# 第二期第 7 章挑战：最大回撤与仓位管理

依照教程使用 AAPL 近三年调整收盘价，策略为 MA10/MA30，信号延迟一天执行；比较满仓与 30% 仓位，并检查最大回撤谷底之后 60 个交易日内是否恢复前高。

## 结果

- 数据区间：2024-01-04 至 2026-11-18，共 722 个用于回测的日收益观测。
- MA10/30 满仓最大回撤：**−27.08%**。
- MA10/30 30% 仓位最大回撤：**−8.77%**，较满仓显著减小。简化比例仓位下，回撤并非严格按比例缩放，因为净值高水位与复利路径也会变化。
- 两个策略最大回撤谷底均为 **2025-08-01**；其后的 60 个交易日中都未恢复到各自此前高点。
- 净值比较：[AAPL_MA10_30_equity.png](AAPL_MA10_30_equity.png)；水下曲线与 −15% 参考线：[AAPL_MA10_30_underwater.png](AAPL_MA10_30_underwater.png)；逐项结果：[drawdown_recovery.csv](drawdown_recovery.csv)；用于复核的调整收盘价：[AAPL_3y_adjusted_close.csv](AAPL_3y_adjusted_close.csv)。

## 思考：最多承受 −15% 回撤，怎么选？

在本次历史样本里，30% 仓位的最大回撤约 −8.77%，低于 −15% 限制；满仓约 −27.08%，超出限制。因此在这两种设定中 30% 仓位更符合约束。若要进一步留出应对未来变化的余量，可以继续降低仓位，或改用其他策略后再用未参与调参的数据检验；历史回撤不保证未来回撤上限。
